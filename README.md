# iPod Original

The first iPod (2001) in the browser, running the 1.3-era software: menus, Now Playing, the scrubber, Clock and Game.

**[Open live demo](https://mitchivin.github.io/ipod-original/) · [Explore in DoodleDev](https://doodledev.app/)**

Works on desktop and phone. Open the live demo and start listening.

![iPod Original Now Playing](assets/ipod-original-playing-device-1920x1080.webp)

## Features

- **1.3-era menus.** Playlists, Browse, Extras, Settings and Backlight, set in Chicago on the 160 × 128 mono LCD.
- **Scroll wheel.** Scroll lists, change volume and scrub through a song.
- **Now Playing.** Track count, title, artist and album, with elapsed and remaining time.
- **Extras.** Clock, Game (Brick) and Import Music for songs from your own device.
- **Backlight and contrast.** Light the screen and set the LCD contrast in Settings.

![iPod Original menu](assets/ipod-original-menu-device-1920x1080.webp)

## Get started

1. Open the [iPod Original live demo](https://mitchivin.github.io/ipod-original/).
2. Go to Browse and choose a song.
3. Use the wheel and buttons to control playback.

This repository hosts the live demo and its product information.
